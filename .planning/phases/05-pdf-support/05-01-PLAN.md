  <action>
1. Install pdfjs-dist:
   ```bash
   npm install pdfjs-dist
   ```

2. Add postinstall script to package.json to copy worker file:
   ```json
   "scripts": {
     "postinstall": "cp node_modules/pdfjs-dist/build/pdf.worker.min.mjs public/pdf.worker.min.mjs"
   }
   ```

3. Run postinstall to copy worker:
   ```bash
   npm run postinstall
   ```

4. Verify worker file exists in public/ folder

Note: The worker must be in public/ with a static path because Vite hashes file names, breaking pdfjs-dist's dynamic worker import. Using `/pdf.worker.min.mjs` as static path avoids this issue.

<task type="auto">
  <name>Task 2: Create PDF processing utility</name>
  <files>src/utils/pdfUtils.js</files>
  <action>
Create `src/utils/pdfUtils.js` with:

1. Configure PDF.js worker source (do once at module load):
   ```javascript
   import * as pdfjsLib from 'pdfjs-dist';
   pdfjsLib.GlobalWorkerOptions.workerSrc = '/pdf.worker.min.mjs';
   ```

2. Create `processPdfToImages(file, maxPages, onProgress)` function:
   - Parameters:
     - `file`: PDF File from file input
     - `maxPages`: Maximum pages to process (default: 5, aligns with MAX_IMAGES)
     - `onProgress`: Optional callback `(current, total) => void`
   - Returns: `Promise<File[]>` - Array of JPEG image files

3. Implementation steps:
   - Convert File to ArrayBuffer, then to Uint8Array
   - Load with `pdfjsLib.getDocument({ data: typedArray }).promise`
   - Calculate pages to render: `Math.min(pdfDoc.numPages, maxPages)`
   - For each page (1-indexed in PDF.js):
     - Call `onProgress(i, numPages)` if provided
     - Get page with `pdfDoc.getPage(i)`
     - Create viewport with scale 2.0 for readable text
     - Create offscreen canvas with viewport dimensions
     - Render page to canvas context
     - Convert canvas to Blob with `canvas.toBlob(resolve, 'image/jpeg', 0.85)`
     - Create File from Blob: `new File([blob], \`${file.name}-page-${i}.jpg\`, { type: 'image/jpeg' })`
     - Call `page.cleanup()` to free memory
   - After all pages: call `pdfDoc.destroy()` to free document memory
   - Return array of image files

4. Export the function

Key settings (from research):
- Scale factor: 2.0 (good text readability)
- JPEG quality: 0.85 (balance of quality and size)
- Max pages: Parameterized, default 5 to match MAX_IMAGES

Error handling:
- Let errors bubble up (caller will handle with try/catch)
- Common errors: encrypted PDF, corrupted file, empty PDF (numPages=0)
  </action>
