  <files>supabase/functions/vision-api/index.ts</files>
  <action>
Create the Edge Function with:

1. **CORS headers** (copy exact pattern from auth-management):
```typescript
const corsHeaders = {
  "Access-Control-Allow-Origin": "*",
  "Access-Control-Allow-Headers": "authorization, x-client-info, apikey, content-type, accept",
  "Access-Control-Allow-Methods": "POST, OPTIONS"
};
```

2. **Request interface**:
```typescript
interface ImagePayload {
  data: string;   // base64 data URL: "data:image/jpeg;base64,..."
  type: string;   // MIME type
}

interface VisionRequest {
  query: string;
  images: ImagePayload[];
  mode: 'search' | 'reason' | 'write' | 'standard';
}
```

3. **Mode-specific default prompts** (when query is empty):
- search: "Please analyze this medical image and provide relevant clinical information with evidence-based references."
- reason: "Please analyze this medical image and provide clinical reasoning, including differential diagnoses and next steps."
- write: "Please analyze this medical image and generate appropriate clinical documentation."
- standard: "Please analyze this image and describe what you see."

4. **Medical system prompt**:
```
You are a medical AI assistant helping healthcare professionals analyze medical images.
Provide evidence-based analysis while noting that AI analysis should supplement, not replace, clinical judgment.
Be specific about what you observe but appropriately cautious about definitive diagnoses.
```

5. **Message construction** for OpenAI:
- Build content array with text (if present) and image_url objects
- Use `detail: "auto"` for images (let OpenAI decide based on size)
- Model: `gpt-4o-mini`
- max_tokens: 4096
- stream: true

6. **SSE stream forwarding**:
- Make fetch to OpenAI with streaming
- Forward response.body directly to client
- Set headers: Content-Type: text/event-stream, Cache-Control: no-cache, Connection: keep-alive

7. **Error handling**:
- 429 (rate limit): "Too many requests. Please wait a moment and try again."
- 400 with "image": "Image could not be processed. Please try a different image format."
- 413 or "too large": "Image is too large. Please use a smaller image."
- 500+: "Image analysis failed. Please try again."
- Missing OPENAI_API_KEY: Return 500 with "Service configuration error"
- No images in request: Return 400 with "At least one image is required"

8. **IMPORTANT**: Return CORS headers on ALL responses (success and error). Use errorResponse helper function.

Use Deno.env.get("OPENAI_API_KEY") for the API key.
