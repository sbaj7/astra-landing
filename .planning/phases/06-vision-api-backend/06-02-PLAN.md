Function signature:
```javascript
/**
 * Send images to Vision API for analysis
 * @param {Object} params
 * @param {string} params.query - User's text query (can be empty)
 * @param {Array<{data: string, type: string}>} params.images - Images with base64 data URLs and MIME types
 * @param {string} params.mode - Chat mode (search, reason, write, standard)
 * @returns {Promise<Response>} - Fetch Response object with streaming body
 */
export async function sendVisionRequest({ query, images, mode }) {
  const url = import.meta.env.VITE_VISION_API_URL;

  if (!url) {
    throw new Error('VITE_VISION_API_URL not configured');
  }

  const response = await fetch(url, {
    method: 'POST',
    headers: {
      'Content-Type': 'application/json',
      'apikey': import.meta.env.VITE_SUPABASE_ANON_KEY,
      'Accept': 'text/event-stream'
    },
    body: JSON.stringify({
      query: query || '',
      images: images.map(img => ({
        data: img.data,
        type: img.type
      })),
      mode: mode || 'standard'
    })
  });

  if (!response.ok) {
    const errorData = await response.json().catch(() => ({ error: 'Unknown error' }));
    throw new Error(errorData.error || `Vision API error: ${response.status}`);
  }

  return response;
}
```

Place this function near other API functions in the file (after existing exports but before any utility functions).

Key points:
- Uses VITE_VISION_API_URL from environment
- Includes Supabase anon key as apikey header (matches Edge Function auth pattern)
- Maps images to {data, type} format expected by backend
- Returns the Response object directly so caller can handle streaming
- Throws descriptive error on failure
